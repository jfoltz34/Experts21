# Research Pack Navigation & Citation

**Start with your own knowledge folder:** `knowledge/<your-agent-name>/` holds the consultant's materials for you specifically, and it overrides `docs/` when they conflict. Then use the project's shared knowledge in `docs/`. Read the files you need before answering. Never contradict them silently: if you disagree, say so and explain why.

## Which file answers what

| File | Read it for |
|---|---|
| `docs/README.md` | Executive summary, shared assumptions, open questions |
| `docs/01-market-overview.md` | Population, income, tourism, dining trends, market sizing |
| `docs/02-target-customers.md` | Segments, personas, needs, seasonality |
| `docs/03-competitors.md` | Competitor table, openings/closures, white space |
| `docs/04-startup-costs.md` | Startup budget (low/base/high), benchmarks, capital structure |
| `docs/05-operating-costs.md` | Cost ratios, revenue model, P&L, break-even |
| `docs/06-permits-and-licenses.md` | Licensing, liquor strategy, zoning, sequencing |
| `docs/07-staffing.md` | Org chart, wages, pay plan, labor law, recruiting |
| `docs/08-marketing.md` | Positioning, pre-opening playbook, channels, calendar |
| `docs/09-risks.md` | Ranked risk register, mitigations, go/no-go gates |
| `docs/expert-roster.md` | Who is on the expert team and which skills each has |
| `docs/agent-brains.md` | Each agent's name, personality and model, and why |
| `knowledge/<agent-name>/` | Per-expert documents from the consultant (read your own first) |
| `docs/decision-log.md` | Decisions the consultant has already made. **Check this before recommending anything.** |

## Shared reference concept (keep every answer consistent with it)

- Upscale, full-service, daytime-focused brunch with a full bar, open about 8am-3pm daily.
- About 4,000 sq ft interior plus a covered patio, about 160 seats (150+ needed for the SRX liquor license).
- Location shortlist: Hyde Park / SoHo, Water Street / Channel District, Midtown / Westshore.
- Second-generation restaurant space preferred.
- Average check about \$44 per guest (base case), food plus beverage, before tax and tip.

If a decision in `docs/decision-log.md` changes any of these, the decision log wins.

## Labels

- **Estimate**: an analyst judgment. Treat it as a starting hypothesis and say what would firm it up (a quote, a bid, a broker opinion).
- **Verify**: not yet confirmed against a primary source. Never present it as fact; name who should confirm it.
- The facts are current as of **November 2026**. Florida wages re-index every September 30 from 2027.

## Citing

- Cite the docs file (e.g., "per 05-operating-costs.md") and, for external facts, the original URL listed in that file's Sources section.
- When you add a new external fact, give its source URL and the date you retrieved it.
