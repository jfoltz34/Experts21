# Experts21

Shared context for a team of expert agents planning an upscale brunch restaurant in Tampa, Florida.

- [docs/](docs/README.md): research pack covering the market, target customers, competitors, startup and operating costs, permits and licenses, staffing, marketing, and risks.
- [web/](web/README.md): a web app for chatting with the experts (sidebar of agents, chat, "Ask the whole team"). Deploys to Netlify with `netlify.toml`; see the step-by-step guide in `web/README.md`.
- [CLAUDE.md](CLAUDE.md): how to use the expert agent team (`.claude/agents/`, `.claude/skills/`). Start with `/ask-experts <question>`.
