# Knowledge folder: Kenji, Foodservice Design & Equipment Specialist (`foodservice-designer`)

`foodservice-designer` reads every document in this folder **before answering any question**. Put the consultant's own materials here: anything this expert should know that isn't in `docs/`.

## What belongs here

- Kitchen and bar layouts
- Equipment schedules and cut sheets
- Hood/MEP coordination notes
- Used-equipment inventories from candidate sites

## How to add documents

- Prefer Markdown (`.md`) or plain text. PDFs and images can be read too, but text is faster and cheaper.
- Name files `YYYY-MM-DD-short-topic.md` so the newest is easy to spot.
- Start each file with one line saying what it is and where it came from.
- Documents here override the shared research pack (`docs/`) for this expert. Note conflicts in the file.
- Don't store secrets (passwords, account numbers, personal IDs). This folder is committed to git.
- Material that several experts need belongs in `docs/` instead.
